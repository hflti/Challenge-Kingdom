---
name: فحوصات جاهزية خدمة API
description: سلوك فحوصات الجاهزية في نشر artifact متعدد الخدمات.
---

يجب أن تعيد خدمة الـAPI استجابة صحة `200` على جذرها وعلى `/api` وعلى `/api/healthz`.

**Why:** نجح بناء artifact بالكامل ثم فشلت الترقية؛ سجلات النشر أظهرت فحصاً على `/api` رغم وجود مسار startup مخصص، وكان `/api` يعيد `404`.

**How to apply:** عند تعديل تركيب Express أو إعدادات artifact، اختبر المسارات الثلاثة بأمر تشغيل production قبل إعادة النشر.
