---
name: مسارات API في إنتاج Replit
description: قاعدة توجيه طلبات الواجهة إلى خدمات Node المسجلة في artifact deployment.
---

في نشر Replit لهذا المشروع، يجب أن تستخدم الواجهة مسارات خدمات Node تحت `/api` في التطوير والإنتاج. لا تستخدم شرط `import.meta.env.PROD` لتحويل الطلبات إلى `./api.php`.

**Why:** التحويل إلى ملف PHP جعل المعاينة تعمل بينما فشل دخول الأدمن والمزامنة في النسخة المنشورة؛ ملف JavaScript المنشور كان يطلب مساراً ثابتاً لا يشغله نشر Replit.

**How to apply:** اجعل القيم الافتراضية `/api/accounts` و`/api/kingdom-state`، واترك متغيرات `VITE_*_API_URL` فقط كبديل صريح لاستضافة مختلفة.
